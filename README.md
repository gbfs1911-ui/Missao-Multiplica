# Missão Multiplica 🚀

Jogo educativo Android para praticar multiplicação por meio de uma missão espacial, sem formato de quiz. O jogador recebe encomendas de grupos iguais e abastece a nave com a carga correta.

- Funciona offline.
- Não coleta dados.
- Aplicativo Android nativo com interface HTML/CSS/JavaScript dentro de WebView.

## Gerar APK
O workflow do GitHub Actions compila o APK de depuração e publica `app-debug.apk` como artefato para download.
